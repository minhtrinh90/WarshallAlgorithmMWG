## Warshall Algorithm

The following algorithm computes the transitive closure of a matrix-weighted graph and returns a partition of the vertices into clusters as presented in [1].

### Inputs

* A matrix-weighted graph $$G=(V,E,W),$$ with matrix-weighted adjacency matrix $\mathbf{A}$.
* The terminal time $T_{\rm end}$.

### Output

A partition $\mathcal{C}_G$ of the vertex set $V$ into clusters.

### Algorithm

Let $n=|V|$ be the number of vertices and let $d$ be the dimension of the matrix weights. The algorithm initializes

$$
\mathbf{M}=\mathbf{I}_{dn},
$$

and

$$
\mathbf{A}_0=\mathcal{D}(\mathbf{A}).
$$

At each iteration, the matrices $\mathbf{M}$ and $\mathbf{A}_k$ are updated using the matrix-weighted logical operators $\vee$, $\wedge$, and $\mathcal{D}$:

$$
\mathbf{M}
\leftarrow
\mathcal{D}\left(\mathbf{M}\vee\mathbf{A}_k\right),
$$

$$
\mathbf{A}_k
\leftarrow
\mathcal{D}\left(\mathbf{A}_k\wedge\mathbf{A}\right).
$$

The procedure terminates when either

$$
k\geq \min\{n-1,T_{\rm end}\},
$$

or the matrix $\mathbf{M}$ determines a single cluster containing all vertices.

The final partition is obtained using `findPartition`. The detailed 

### Pseudocode

```text
Algorithm: Warshall Algorithm

Input:
    Matrix-weighted graph G = (V, E, W)
    Matrix-weighted adjacency matrix A
    Terminal time T_end

Output:
    A partition C_G of V into clusters

1.  k ← 0
2.  M ← I_(dn)
3.  A_k ← D(A)

4.  repeat
5.      M ← D(M ∨ A_k)
6.      A_k ← D(A_k ∧ A)
7.      k ← k + 1
8.  until k ≥ min{n − 1, T_end}
       OR {V} = findPartition(M, n, d)

9.  return findPartition(M, n, d)
```

The algorithm calls the findPartition procedure to create a partition of the graph based on the present matrix $M$.

### `findPartition`

```text
Procedure: findPartition

Input:
    M ∈ R^(nd × nd), n, d

Output:
    Partition C_G of {v_1, ..., v_n}

1.  [c_1, ..., c_n] ← [1, ..., n]
2.  C_G ← {{v_1}}
3.  i ← 1

4.  repeat
5.      if c_i = i then
6.          clt ← {v_i}
7.      else
8.          clt ← C_(c_i)
9.      end if

10.     j ← i + 1
11.     repeat
12.         if c_j = j AND [M]_(ij) = I_d then
13.             clt ← clt ∪ {v_j}
14.             c_j ← c_i
15.         end if
16.         j ← j + 1
17.     until j > n

18.     C_(c_i) ← clt
19.     C_G ← C_G ∪ {C_(c_i)}
20.     i ← i + 1

21. until i > n

22. return C_G
```


### Mathematical Form

The iterative part of the algorithm can be summarized as

$$
\boxed{
\begin{aligned}
\mathbf{M}_{k+1}
&=
\mathcal{D}
\left(
\mathbf{M}_k\vee\mathbf{A}_k
\right),\\
\mathbf{A}_{k+1}
&=
\mathcal{D}
\left(
\mathbf{A}_k\wedge\mathbf{A}
\right).
\end{aligned}}
$$

with initial conditions

$$
\mathbf{M}_0=\mathbf{I}_{dn},
\qquad
\mathbf{A}_0=\mathcal{D}(\mathbf{A}).
$$

The algorithm stops after at most

$$
\min\{n-1,T_{\rm end}\}
$$

iterations unless all vertices have already been identified as belonging to the same cluster.

### Interpretation

The matrix $\mathbf{M}$ accumulates connectivity information generated by paths of increasing length. The operator $\mathcal{D}(\cdot)$ extracts the relevant matrix-valued information required by the algorithm.

The function

```text
findPartition(M, n, d)
```

converts the resulting matrix $\mathbf{M}$ into a partition $\mathcal{C}_G =\{C_1,C_2,\ldots,C_q\}$ of $V$.

If $$\{V\}={\rm findPartition}(\mathbf{M},n,d),$$ then all vertices belong to a single cluster and the algorithm terminates early.

### Notes

The commented-out section in the original LaTeX implementation contains an earlier implementation of the partition procedure. It is omitted from the main pseudocode above because the current algorithm delegates this operation to

```text
findPartition(M, n, d)
```

This makes the Warshall procedure independent of the particular implementation used to extract the final vertex partition.
